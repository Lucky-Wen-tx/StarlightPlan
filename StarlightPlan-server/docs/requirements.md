# 拾光Plan 后端 MVP 需求规范
## 技术栈
- FastAPI + Pydantic v2 + uvicorn
- 存储：本地文件系统，笔记以 .md 文件形式存在指定目录
- 部署：单服务启动，后期托管前端静态资源

## 核心功能
1. 笔记CRUD：新建、获取列表、获取单篇内容、更新内容
2. 回收站：删除笔记移入 .recycle 目录，支持恢复、永久删除
3. 文件操作：MD文件导入、图片上传存入assets目录
4. 路径安全：所有文件操作限制在笔记根目录，防止路径穿越
5. 文件名校验：自动过滤Windows非法文件名字符

## 代码规范
- 严格类型提示，所有接口参数用 Pydantic 校验
- 业务逻辑抽离到 services 层，main.py 只做路由注册
- 统一错误处理，用 HTTPException 返回标准错误码
- 接口路径统一前缀 /api
